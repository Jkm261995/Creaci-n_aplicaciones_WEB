# 🧮 Calculadora Web

Calculadora funcional desarrollada con HTML, CSS y JavaScript puro.

## ✨ Características

- Suma, resta, multiplicación, división y porcentaje
- Soporte de teclado físico
- Diseño responsive (celular y PC)
- Manejo de errores (división entre cero, expresiones inválidas)

## 🛠️ Tecnologías

- HTML5 (estructura)
- CSS3 con Grid y Flexbox (diseño)
- JavaScript ES6 (lógica)

## ▶️ Cómo ejecutar

1. Clona o descarga el repositorio
2. Abre `index.html` en tu navegador
